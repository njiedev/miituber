One-time setup: add the Mii resource file

MiiTuber renders Miis with Nintendo's official Mii resource file, AFLResHigh_2_3.dat. It can't be bundled for copyright reasons, so add it once and you're set.

  1. Download the Miitomo archive from the Internet Archive (the link is in the README on our GitHub page).
  2. Unzip it to get AFLResHigh_2_3.dat.
  3. Click below and select that file.

Already have it from another Mii app (sometimes named ffl_hires.dat)? That works too.
