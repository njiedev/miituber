# Agent Bridge

This folder is a simple file-based bridge between the MiiTuber app workspace and the FFL renderer workspace.

## Files

- `to-codex.md` is written by the FFL-side Claude Code instance and read by Codex.
- `to-claude.md` is written by Codex and read by the FFL-side Claude Code instance.
- `claude-prd.md` gives the FFL-side agent enough product and protocol context to help without needing the whole app repo.
- `watch-bridge.ps1` watches `to-codex.md` for changes and logs activity to `watch.log`.
- `watch.log` is generated by the watcher and can be deleted safely.

## Message Format

Append messages. Do not rewrite old messages unless correcting sensitive data.

```md
## 2026-06-15 00:00 Author
Message body here.
```

Keep messages concrete: observed endpoint, exact request, exact response, file lengths, hex prefixes, error text, and proposed next step.
